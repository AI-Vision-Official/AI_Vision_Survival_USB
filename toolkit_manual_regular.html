Offline Toolkit Manual

What is the Offline Toolkit?

The Offline Toolkit is a set of helpful programs that work without internet. You can keep them on a USB stick or computer and use them in emergencies.

How to use it?

  • Plug in the USB stick or open the folder with the tools
  • Click on the tool you want (example: Kiwix to read Wikipedia)
  • No internet is needed to use the tools

Recommended tools

  • Kiwix: Read Wikipedia offline
  • Everything: Search your files instantly
  • LibreOffice: Write texts, open spreadsheets
  • 7-Zip: Open ZIP files

Tips

  • Keep your tools up to date
  • Print this manual if possible
  • Use the same folder every time, so you don’t lose files

Wat is de Offline Toolkit?

De Offline Toolkit is een verzameling handige programma’s die werken zonder internet. Je kunt ze bewaren op een USB-stick of computer en gebruiken in noodgevallen.

Hoe gebruik je het?

  • Steek de USB-stick in of open de map met de tools
  • Klik op het programma dat je wilt gebruiken (bijvoorbeeld Kiwix voor Wikipedia)
  • Internet is niet nodig om deze tools te gebruiken

Aanbevolen programma’s

  • Kiwix: Wikipedia offline lezen
  • Everything: Direct zoeken op je computer
  • LibreOffice: Teksten schrijven, spreadsheets openen
  • 7-Zip: ZIP-bestanden openen

Tips

  • Houd de tools up-to-date
  • Print deze handleiding indien mogelijk
  • Gebruik telkens dezelfde map, zo raak je niets kwijt
